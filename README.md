# MrNewbWeaponTints

ox_inventory tint items plus a heavy file that strips weapon serials.

These items use ox_inventory `server.export` on purpose. That is the exception to the usual MrNewb item rule.

[Documentation](https://mrnewb.github.io/docs/mrnewbweapontints) · [GitHub](https://github.com/MrNewb/MrNewbWeaponTints) · [Discord](https://discord.gg/mrnewbscripts)

## Install

Needs [ox_lib](https://github.com/overextended/ox_lib), [ox_inventory](https://github.com/overextended/ox_inventory), and [Newb_Bridge](https://github.com/MrNewb/Newb_Bridge).

```cfg
ensure ox_lib
ensure ox_inventory
ensure Newb_Bridge
ensure MrNewbWeaponTints
```

Paste the items from [inventory setup](https://mrnewb.github.io/docs/mrnewbweapontints/install/inventory). Each tint sets `server.tint` (1–7). MK2 weapons remap when the weapon item name contains `MK2`.
